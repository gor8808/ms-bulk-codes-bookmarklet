Импорт в отгрузку

Загрузите файл результата сборки WB с колонкой «КИЗ». Приложение посчитает товары по штрихкоду из каждого КИЗ и подготовит CSV для импорта позиций в отгрузку МойСклад. Файл обрабатывается только на этом компьютере.

Как импортировать CSV в отгрузку МойСклад

Импорт добавляет товары и количество. Сами коды маркировки (КИЗ) к позициям при этом не прикрепляются.

  1. Откройте отгрузку и сохраните её. Под таблицей товаров нажмите Импорт → Импортировать.

  2. Нажмите Загрузить и выберите скачанный CSV.

  3. Выберите Кодировка: UTF-8 и Искать: Автоматически. Снимите обе галочки: «обновить информацию по существующим товарам» и «создать новые товары» — так карточки товаров не изменятся.

  4. Проверьте столбцы: Штрихкод GTIN, Штрихкод EAN13, Количество. Затем нажмите зелёную кнопку Импорт вверху страницы.

  5. Дождитесь надписи «Задача завершена», нажмите Закрыть и откройте отгрузку снова — товары появятся с нужным количеством. Если какой-то товар не добавился, нажмите «Посмотреть результаты»: скорее всего, в МойСклад нет товара с таким штрихкодом.
