# WB: подгонка цены под акцию

Для `seller.wildberries.ru` → «Цены и скидки». В карточке товара у каждой акции
появляется кнопка **Подогнать**: она подбирает «Скидку продавца» и «Цену продавца до скидки»
так, чтобы цена со скидкой была не выше цены участия в акции и отличалась от неё меньше чем на 1 ₽.

## Установка (один раз)

1. Установите **Tampermonkey** из Chrome Web Store: https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo
2. Разрешите ему запускать скрипты: `chrome://extensions` → Tampermonkey → «Подробнее» →
   включите **«Разрешить пользовательские скрипты»** (в старых версиях Chrome вместо этого включите «Режим разработчика» справа сверху)
3. Откройте ссылку и нажмите **Установить**:
   **https://raw.githubusercontent.com/gor8808/ms-bulk-codes-bookmarklet/main/wb-extension/wb-price-fit.user.js**
4. Обновите страницу «Цены и скидки»

Обновления приходят автоматически (Tampermonkey проверяет раз в сутки).
Проверить сейчас: иконка Tampermonkey → «Утилиты» → «Проверить обновления».

## Как пользоваться

1. Откройте товар (кликните по строке таблицы)
2. В блоке «Цена для участия в акции» нажмите **Подогнать** у нужной акции
3. Проверьте предпросмотр и нажмите **Применить**: поля заполнятся
4. Нажмите **Сохранить** в WB (скрипт сам ничего не сохраняет)

## Как считается

Скидка в приоритете, цена только доводит до точного значения:

```
Скидка = max(текущая, ceil(100 − 100 × T / Цена))
Цена   = floor(100 × T / (100 − Скидка))
```

`T` — «до N ₽» из карточки акции. Скидка никогда не уменьшается. Подробнее:
[docs/plans/2026-11-22-wb-promo-price-fit-design.md](../docs/plans/2026-11-22-wb-promo-price-fit-design.md).

## Для разработки

- Математика: `lib/price-fit.js` (без DOM). Селекторы страницы: `lib/selectors.js`. Интерфейс: `content.js`.
- `wb-price-fit.user.js` собирается из этих файлов, руками не править.

Выпустить обновление:

1. Измените код
2. Поднимите `"version"` в `manifest.json` (например `0.1.0` → `0.1.1`)
3. `npm run build:wb-userscript`
4. `npm run test:wb-extension` — тест упадёт, если код изменился, а версия нет
5. Влейте в `main` — у всех обновится в течение суток

Альтернатива без Tampermonkey: `chrome://extensions` → «Режим разработчика» →
«Загрузить распакованное расширение» → папка `wb-extension` (обновления вручную).
